## Размещение Telegram-бота бесплатно через Render

Render — это бесплатный хостинг с поддержкой Docker-контейнеров. Инструкция:

### Шаг 1. Регистрация и настройка
1. Перейдите на https://render.com и зарегистрируйтесь (можно через GitHub).
2. Нажмите "New Web Service".
3. Подключите ваш GitHub-репозиторий или загрузите проект.
4. Укажите:
   - Environment: `Docker`
   - Build Command: *(оставьте пустым)*
   - Start Command: `docker-compose up --build`
   - Instance Type: `Free`
5. Добавьте переменные окружения:
   - `BOT_TOKEN` — токен вашего Telegram-бота
   - `DB_URL` — строка подключения PostgreSQL (если используете внешний сервис, например Supabase)

### Шаг 2. PostgreSQL (если не хотите локальную БД)
1. Зарегистрируйтесь на https://supabase.com
2. Создайте новый проект и получите строку подключения.
3. Подставьте её в `.env` или в Render Environment Variables.

### Шаг 3. Запуск
- После деплоя Render сам запустит контейнер.
- Бот станет доступен и будет работать в Telegram.

*Готово! Ваш бот работает онлайн бесплатно.*

## Подключение PostgreSQL через Supabase (бесплатно)

Если вы не хотите настраивать базу данных вручную, воспользуйтесь Supabase.

### Шаг 1. Регистрация
1. Перейдите на https://supabase.com и зарегистрируйтесь.
2. Нажмите **"New Project"**.
3. Введите:
   - Название проекта
   - Пароль для базы данных
   - Выберите регион (любой)

### Шаг 2. Получение строки подключения
1. Перейдите в созданный проект → вкладка **Settings → Database**.
2. Скопируйте поле **Connection string** (тип: `PostgreSQL`).
3. Пример:
   ```
   postgresql://postgres:<your-password>@db.<project>.supabase.co:5432/postgres
   ```

### Шаг 3. Настройка в проекте
1. Вставьте эту строку в переменную `DB_URL` в `.env` или в Render:
   ```
   DB_URL=postgresql://postgres:ваш_пароль@.../postgres
   ```

### Шаг 4. Готово
- Теперь ваш бот будет использовать онлайн-базу, доступную 24/7.
- Supabase бесплатен до 500 МБ и отлично подходит для начала.
